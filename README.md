# sistema-telecom
Sistema de gestão de manutenção e ocorrências para telecom

Sistema de Gestão de Telecom
📌 Objetivo

Sistema desenvolvido para gerenciar ocorrências, ordens de serviço e equipes técnicas no setor de telecomunicações, visando reduzir o tempo de atendimento e melhorar a segurança operacional.

🚨 Problemas abordados
Falta de mão de obra especializada
Alto risco nas atividades de campo
Demora na resolução de falhas
Falta de controle operacional
🧩 Funcionalidades do sistema
Cadastro de ocorrências
Geração de ordens de serviço (OS)
Atribuição de equipes técnicas
Monitoramento de status em tempo real
Controle de SLA (tempo de atendimento)
